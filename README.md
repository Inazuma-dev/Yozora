## ✦ About

**Yozora** is an experimental, open-source browser project exploring how AI-assisted browsing could work on older iPhones.

The goal is to combine a clean, modern browsing experience with contextual AI features and a distinctive interface inspired by dark aesthetics, Liquid Glass and futuristic design.

Yozora is being developed with compatibility with older iOS versions in mind, starting with iOS 15.

> **Project status:** Early development. Features, compatibility and the final design are still being worked on. Yozora is not ready for everyday use yet.

## ✧ Vision

- **Browse naturally** — a focused interface for navigating the web.
- **Understand more** — explore AI-assisted search, page summaries and contextual questions.
- **Stay organised** — tabs, bookmarks and browsing history in one place.
- **Keep it open** — public source code, transparent development and community contributions.
- **Respect older hardware** — investigate performance and compatibility on older iPhones.

## ⌘ Tech stack

- **Swift** — application logic
- **SwiftUI** — native user interface
- **WebKit / WKWebView** — web content rendering
- **Xcode** — development and testing
- **Git & GitHub** — version control and collaboration

The initial compatibility target is iOS 15.0 and later, with actual support to be verified through device testing.

## ◇ Design direction

Yozora aims for a distinctive visual identity:

- Dark surfaces with subtle violet and cyan gradients
- Translucent panels and restrained glass effects
- Clean typography and generous spacing
- Smooth, purposeful animations
- A mobile-first layout designed around the iPhone

The visual direction may evolve as development progresses.

## 🛠 Development

Development requires a Mac with Xcode and an iPhone or simulator running a supported iOS version.

**Getting started:** the application source and Xcode project are not yet available in this initial repository stage. Build instructions will be added once the project structure is in place.

When development files are available, the intended workflow will be:

1. Clone the repository.
2. Open the Xcode project or workspace.
3. Select a supported simulator or connected iPhone.
4. Build and test the application.

## 🤝 Contributing

Potential ways to help include:

- Reporting bugs

## 🔐 Privacy

Privacy is an important design consideration for Yozora.

AI features may involve external services, depending on the final implementation. Before such features are released, the project should document what data is sent, which providers are used and what configuration options are available.

Do not submit API keys, passwords or personal data in public issues or commits.
