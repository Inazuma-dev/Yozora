# Yozora

**An open-source, AI-powered web browser for iOS 15.0–16.x.x.**

Yozora is an experimental browser project focused on combining a modern browsing experience with AI-powered tools and a distinctive dark, glass-inspired interface.

> **Status: Early development.** Yozora is a work in progress and is not yet ready for everyday use.

## ✨ Vision

Yozora aims to make browsing more intuitive, personal, and intelligent.

- 🌐 **Modern browsing** — a clean, immersive web experience.
- 🤖 **AI assistance** — get help understanding web content and asking questions.
- 📄 **Ask this page** — interact with the content of the current webpage using AI.
- 🗂️ **Tab management** — keep browsing sessions organized.
- 🔖 **Bookmarks and history** — quickly return to useful pages.
- 🪟 **Liquid Glass-inspired UI** — translucent surfaces, layered blur, subtle gradients, and a dark cyber-inspired aesthetic.
- 🔓 **Open source** — a project developed transparently with community contributions in mind.

*These are project goals, not a list of features that are already implemented.*

## 📱 Compatibility

- **Target platform:** iOS 15.0–16.x.x
- **Primary development language:** Swift
- **UI framework:** SwiftUI
- **Web rendering:** WebKit / WKWebView
- **Development environment:** Xcode

Compatibility with specific devices and iOS versions will be verified as development progresses.

## 🎨 Design

Yozora's visual identity combines a dark cyber aesthetic with modern glassmorphism.

The design direction includes:

- Translucent, layered interface elements
- Soft blur and depth effects
- Subtle gradients and atmospheric lighting
- Minimal, immersive navigation controls
- A distinctive visual identity built around the Yozora logo
